# Track 1 Echo 示例目录

本目录用于放置 Track 1 的公开样例文件。

建议最小样例：

- `sample_echo_arc.mat`
- `sample_echo_slice.mat`
- `sample_isar.webp`
- `sample_meta.txt`

建议说明：

- `sample_echo_arc.mat`：弧段级复数回波
- `sample_echo_slice.mat`：与单帧图像严格对齐的回波切片
- `sample_isar.webp`：对应的 ISAR 图像预览
- `sample_meta.txt`：帧级几何、PRF、时间等 sidecar 信息

当前发布页仅提供目录骨架，待后续补充可公开样例。
