# Track 4 Gen 示例目录

本目录用于放置 Track 4 的公开样例文件。

建议最小样例：

- `sample_isar.webp`
- `sample_optical.webp`
- `sample_optical_isar_view.webp`
- `transforms_train.json`

建议说明：

- `sample_isar.webp`：ISAR 模态图像
- `sample_optical.webp`：同姿态光学图像
- `sample_optical_isar_view.webp`：与 ISAR 成像平面对齐的光学视图
- `transforms_train.json`：3DGS / NeRF 训练所需的位姿文件

当前发布页仅提供目录骨架，待后续补充可公开样例。
