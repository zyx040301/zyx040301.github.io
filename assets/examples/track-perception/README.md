# Track 5 Perception 示例目录

本目录用于放置 Track 5 的公开样例文件。

建议最小样例：

- `sample_isar.webp`
- `sample_meta.txt`
- `sample_echo_slice.mat`
- `manifest.csv`

建议说明：

- `sample_isar.webp`：感知任务使用的帧级 ISAR 图像
- `sample_meta.txt`：该帧对应的几何与成像 sidecar
- `sample_echo_slice.mat`：与图像窗口一一对应的回波切片
- `manifest.csv`：协议化样本索引，可附带类别、split、协议标签

当前发布页仅提供目录骨架，待后续补充可公开样例。
