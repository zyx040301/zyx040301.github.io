ASTRA-ISAR

A Space-Target Radar Benchmark for Imaging, Generation, and Perception

星穹空间目标 ISAR 多任务基准

ASTRA-ISAR（A Space-Target Radar Benchmark for Imaging, Generation, and Perception）面向空间目标雷达感知与成像研究，中文标准名为“空间目标雷达成像、生成与感知基准”。数据集围绕统一的物理观测链组织 LOS 几何、复数回波、ISAR 图像、光学对齐视图、几何字段与语义标注，不是若干单任务样本集的简单拼接，而是试图把同一目标在同一观测逻辑下的多层级数据整理为同源、可追溯、便于复现实验的数据基座。

数据集按 Echo、Enhance、Geo、Gen、Perception 五个 Track 组织，从底层电磁观测延伸到高层分类、检测与分割。当前版本为预发布说明页，优先明确任务边界、数据组织、协议逻辑与目标分类依据，使使用者能够快速理解各 Track 的适用问题与使用入口。

为什么需要 ASTRA-ISAR

依据现有公开文献整理，空间目标 ISAR 研究仍缺少公开发布、结构统一、覆盖从回波到感知完整链路的多任务基准；已有数据多服务于单篇论文或单一任务，难以形成可持续复用的开放入口。

协议应带有观测几何意义

仅有随机 train / test 划分不足以支撑空间目标评测。ASTRA-ISAR 强调弧段、视角与观测条件的可解释协议，使相似条件泛化与外推条件泛化能够被清楚地区分。

同源观测链支持跨层级研究

原始回波、成像、几何、跨模态生成与感知任务通常彼此割裂。ASTRA-ISAR 的目标是把这些层级重新连接起来，使算法能够在共享物理来源的前提下进行对齐分析与联合建模。

Five Tracks

五个 Track

五个 Track 共同构成从底层复数观测到高层任务评测的完整研究链路。它们共享统一的目标模型、观测几何与成像主链，同时分别突出原始回波、物理退化、连续几何、跨模态对齐与协议化感知等不同研究入口。

Track 1 Echo

原始回波与微动建模

Raw Echo & Micro-Motion

Track 1 保留底层二维复数域回波，而不是只发布最终图像。弧段级 Echo、帧级 Echo Slice 与对应 ISAR 图像构成可一一追溯的监督链，适合前端成像、自聚焦、运动补偿与微动估计等问题。

数据形态

弧段级复数回波 .mat、帧级回波切片 .mat、对应 ISAR 图像与几何 sidecar。

任务与指标

自聚焦、运动补偿、微动估计、回波到聚焦成像建模；常用指标包括 PSLR、ISLR、图像熵、对比度与成像链一致性。

示例与状态

该 Track 已具备回波、切片与成像严格同源的预发布基础，可直接用于信号处理与端到端建模。

Track 2 Enhance

物理退化与图像恢复

Physics-Grounded Degradation & Restoration

Track 2 面向雷达特有退化，而非通用视觉中的高斯噪声假设。它从回波链路出发注入相位误差、平动误差、接收机噪声等物理退化，并逐步扩展到频域截断、旁瓣与 speckle 等更完整的恢复问题。

数据形态

<退化回波, 理想回波> 或 <退化图, 理想图> 的成对样本，强调退化机理明确、真值可追溯。

任务与指标

盲超分辨、去噪、旁瓣抑制与物理驱动恢复；评测可结合 ENL、PSNR、SSIM 以及结构与物理一致性。

示例与状态

该 Track 已具备物理退化注入底座，正式发布版本将继续补齐更完整的退化族和统一成对打包协议。

Track 3 Geo

连续几何与三维散射重建

Continuous Geometry & 3D Scatter Reconstruction

Track 3 面向连续多视角几何恢复与三维散射建模。它强调姿态变化平滑、视角采样连续以及面向 3DGS / NeRF 的可训练几何导出格式，使几何字段不仅可看，而且可直接进入重建模型。

数据形态

多视图 ISAR 序列、姿态 / 法向量 / 几何字段，以及 transforms_train.json、transforms_test.json 等训练接口。

任务与指标

3DGS、NeRF、多视图一致性建模、三维散射恢复；可关注渲染 PSNR、几何误差、RCS 一致性与跨视图稳定性。

示例文件说明
Track 4 Gen

跨模态对齐生成与多波段泛化

Cross-Modal Aligned Generation & Multi-Band Generalization

Track 4 并非从真实轨道弧段出发，而是从人为设计的全视角观测分布出发构造严格对齐的跨模态样本。它以近似均匀球面采样生成全姿态观察方向，并在每个方向上同步导出 ISAR、Optical、Optical_ISAR_View、EchoSlice 以及可继续进入 3DGS / NeRF 的训练接口，用于支撑姿态条件生成、跨模态翻译与多波段泛化研究。

视角与姿态生成
  • 默认在单位球面上近似均匀采样 120 个观察方向，可理解为接近 Fibonacci sphere / golden spiral 的全姿态分布。
  • 每个方向默认 PRF = 100 Hz、Duration = 6 s、RotationSpeed = 0.02 rad/s，因此约生成 600 个慢时间采样点，总局部转角约 6.87°。
  • 默认以本体 Z 轴投影作为等效自旋轴；当视线接近自旋轴方向时，退化到本体 X 轴作为备用旋转轴。
配对与导出

输出 ISAR、Optical、Optical_ISAR_View、EchoSlice，并可进一步整理为 transforms_train.json / transforms_test.json。在默认链路下，单模型通常得到约 120 组对齐样本，并采用 9:1 规则划分训练与测试。

任务与指标

光学到 ISAR 生成、姿态条件生成、sim-to-real 迁移与多波段泛化；可结合 FID、结构保真度、相位与多普勒一致性评估。

多波段设置
  • C-band：5 GHz / 0.5 GHz
  • X-band：10 GHz / 1 GHz
  • Ku-band：16 GHz / 1.5 GHz
  • 多波段扩展仅属于 Track 4，用于跨模态生成与跨频段泛化，不外推为全数据集统一设定。
示例与状态

该 Track 已形成严格对齐的全视角跨模态导出链路，并保留继续接入 3DGS / NeRF 训练格式的接口。

Track 5 Perception

分类、检测与分割

Classification, Detection & Segmentation

Track 5 基于真实轨道可视弧构造协议化感知数据。它的最小协议单元不是单个 TLE 文件，而是带有明确几何含义的 (TLE, ArcIndex) 组合；因此 SOC 与 EOC 的区别对应真实可复现的观测条件差异，而不是随机文件夹划分。该 Track 以分类为主，同时覆盖部件检测与分割，并用于评估跨观测条件泛化。

数据形态

帧级 ISAR 图像、几何 sidecar、对应 Echo Slice，以及类别标签、BBox、Mask 等高层注释。

任务与指标

任务顺序为 分类 -> 部件检测 -> 分割；指标顺序为 Top-1 Acc -> mAP -> mIoU。

协议参数

当前主链以 X 波段为主，默认 Fc = 10 GHz、Bw = 1 GHz、PRF = 50 Hz、ImgSize = 512、可视俯仰角阈值 3°、StartT = 100、StepCoef = 0.25。

Taxonomy

二维分类体系：Topology × Scale

ASTRA-ISAR 不按“任务功能”划分类别，而采用“主导散射拓扑 + 电尺寸难度”的二维框架。这样定义的标签更接近 ISAR 图像中真正起作用的镜面反射、边缘绕射、二面角、腔体谐振、自遮挡与复杂微多普勒等物理因素。

拓扑类 A / B / C / D

  • Class A：紧凑主体型，闭合凸包、展开部件少，适合作为紧凑体与小目标参考基线。
  • Class B：非对称展开型，单侧翼面或偏置载荷主导，适合研究重心偏移与非对称微动。
  • Class C：对称多翼展开型，双翼或多翼对称展开，是对称结构建模与 InISAR 重建的重要参考族。
  • Class D：强载荷与复杂桁架型，大型天线、深腔与复杂组合体主导，是大目标难例上限库。

尺度级 S / M / L

  • S 级：最大跨度不超过 1.5 m，适合验证极小电尺寸目标与全波求解边界。
  • M 级：最大跨度介于 1.5 m 到 10 m，适合研究中等尺寸目标的轮廓、二面角与部件结构。
  • L 级：最大跨度超过 10 m，复杂自遮挡、多级衍射与强相干散斑显著，是大型目标核心挑战区间。
A: 紧凑主体型 B: 非对称展开型 C: 对称多翼展开型 D: 强载荷与复杂桁架型 S / M / L: 电尺寸与求解难度分级
